# Premium Designer Portfolio

A modern, minimal portfolio website designed for a Senior Product Designer. Built with **React**, **Vite**, and **Tailwind CSS**.

## Features

- **Minimal & Premium Aesthetic**: Grid-based layout inspired by Apple, Linear, and Vercel.
- **Product-Focused Microcopy**: Emphasizes systems thinking, scalability, and impact.
- **Fully Responsive**: Optimized for all screen sizes from mobile to desktop.
- **Smooth Interactions**: Subtle fade-ins and hover effects powered by Framer Motion.
- **Clean Architecture**: Organized into reusable components and logical sections.

## Tech Stack

- **React 19**: Modern functional components with hooks.
- **Vite**: Ultra-fast build tool and dev server.
- **Tailwind CSS**: Utility-first styling for maximum performance.
- **Lucide React**: Clean, consistent iconography.
- **Framer Motion**: Smooth micro-interactions.

## Project Structure

```text
/src
  /components     # Reusable UI elements (Button, Card, Section, Container)
  /sections       # Main page sections (Hero, About, Work, etc.)
  /data           # Content and project definitions
  /assets         # Static assets and icons
  App.jsx         # Main application assembly
  index.css       # Global styles and Tailwind base
```

## Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

## Design Philosophy

This portfolio is built with the "Designer who Codes" persona in mind. It prioritizes:
1. **Hierarchy**: Large, bold typography for immediate impact.
2. **Whitespace**: Intentional breathing room to let the work shine.
3. **Systems Thinking**: Evidence of product logic and complex workflow management throughout the microcopy.
